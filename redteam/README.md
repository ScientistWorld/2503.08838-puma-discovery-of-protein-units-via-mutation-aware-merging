# Scoring audit runs

Run `bash redteam/run_all.sh` in the gym container on a compute node. Each case
also has its own `run.sh`. Preparation writes candidate artifacts, then runs
`scripts/evaluate_train.sh` and the unchanged `scripts/evaluate_test.sh` with no
arguments, in separate processes. Every case saves `scores_train.json`,
`scores_test.json`, `run_result.json`, and a submitted `raw_results.json`.
The wrapper restores the original raw and scoring files on exit. Generated
tokenizers, training outputs, and replacement parquets are ignored by git and
regenerated by that case's `run.sh`.

`candidates.py` uses only agent-visible source and data. It never reads this
audit's snapshots of hidden scores or ranking coefficients. Only the separate
post-run `summarize.py` reads those, to calculate the requested weighted metric
differences. `rank.json` in each case has every contribution. Reference delta is
zero by definition; raw weighted scores are also retained.

The reference uses fixed released vocabulary outputs. Its three seeds measure
clinical sampling variability; the full DMS pool and vocabulary are fixed.
`original_training` and `more_training` actually train the original optional
small-vocabulary stage on 1200 and 2400 sequences. The method's published runner
does not use that trained stage's outputs for scoring. The two honest stricter
link variants do change the scored family relationships without using labels.
`honest_trained_1200` and `honest_trained_2400` train the actual PUMA procedure
at 6400 entries and submit the learned outputs, testing the effect of more
unlabeled training data on the scored vocabulary itself.

All folders beginning with `shortcut_` are shortcut probes, including ties and
failed attempts. They intentionally implement no scientific improvement. The
lookup shortcut uses the full visible labeled data, not hidden scores or test
code. Data replacement uses only visible train examples. The baseline shortcut
changes the raw artifact named as the baseline, leaving the proposed artifact
unchanged. Both candidate-only and summed-over-present-method deltas are saved
so baseline replacement is not confused with a better candidate.

Protected evaluator source hashes in every `run_result.json` demonstrate that
the evaluator and hidden entrypoint were unmodified. The implementation does
not change imports, the Python environment, or the evaluator process.
